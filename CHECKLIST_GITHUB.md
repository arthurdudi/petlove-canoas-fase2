# Checklist: Publicação no GitHub Pages

Use este checklist para garantir que tudo está correto antes de entregar o projeto.

## Antes de Criar o Repositório

- [ ] Todos os arquivos HTML estão prontos
- [ ] README.md está completo
- [ ] OBJETIVO_METAS.md está completo
- [ ] ajuda.md está completo
- [ ] Todos os links entre páginas funcionam localmente
- [ ] Todas as imagens estão carregando (placeholders)

## Criar Repositório no GitHub

- [ ] Criar conta no GitHub (se ainda não tiver)
- [ ] Criar novo repositório público
- [ ] Nome do repositório: _________________________
- [ ] Fazer upload de todos os arquivos:
  - [ ] index.html
  - [ ] produtos.html
  - [ ] servicos.html
  - [ ] README.md
  - [ ] OBJETIVO_METAS.md
  - [ ] ajuda.md
- [ ] Fazer commit inicial

## Configurar GitHub Pages

- [ ] Ir em Settings → Pages
- [ ] Selecionar "Deploy from a branch"
- [ ] Branch: main (ou master)
- [ ] Folder: / (root)
- [ ] Salvar configurações
- [ ] Aguardar publicação (até 5 minutos)

## Verificar Site Publicado

- [ ] URL do GitHub Pages: _________________________
- [ ] Página inicial carrega corretamente
- [ ] Link "Produtos" funciona
- [ ] Link "Serviços" funciona
- [ ] Navegação entre páginas funciona
- [ ] Todas as imagens aparecem
- [ ] Footer aparece em todas as páginas
- [ ] Header aparece em todas as páginas

## Atualizar Documentação

- [ ] Atualizar README.md com link do repositório
- [ ] Atualizar README.md com link do GitHub Pages
- [ ] Fazer commit das atualizações
